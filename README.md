# Radio Maitino - Generador Automático de Boletín MP3 (60s)

Este repositorio contiene un servidor en **Node.js** que genera de forma automática y continuada un archivo `.mp3` de **exactamente 60 segundos** con el boletín meteorológico de Elche.

## 🚀 Requisitos Previos
Debes tener instalado en tu servidor o máquina:
- **Node.js** (versión 18 o superior recomendada)
- **FFmpeg** instalado en el sistema (es obligatorio para que Node.js procese y recorte el audio exactamente a 60s).

## 📥 Instalación

1. Clona este repositorio o descarga los archivos.
2. Instala las dependencias:
